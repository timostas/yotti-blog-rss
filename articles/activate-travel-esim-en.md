Activating an eSIM involves adding the provider's profile, turning on the new line and selecting it for mobile data. A travel package can have a separate validity trigger. Depending on the plan, the clock may start at installation, first connection to a supported network or another specified event.

Open the order for the selected [Yotti plan](https://yotti.net/en/) and identify the installation method, validity trigger and roaming requirement before touching the phone settings.

## Add the profile supplied with the order

On iPhone, open Settings, Cellular and Add eSIM. Apple supports QR codes, provider links, apps, manual details and carrier activation. Use the method attached to the order rather than trying each option.

On Pixel, open Settings, Network & internet, SIMs, Add SIM and Set up an eSIM. Samsung places Add eSIM inside SIM manager. Approve the download and wait for a new line to appear.

The visible profile confirms a successful download. It does not by itself prove that the line can register at the destination or that package validity has started.

## Assign a clear job to each line

Label the profiles “Home” and “Travel”. Keep the home number for calls and messages if needed, while selecting Travel for mobile data. Prevent the home SIM from using data abroad.

Set data roaming on the travel line according to the plan instructions. International eSIMs often need it because they connect through a partner carrier. The setting belongs to that line; it is not a reason to enable roaming everywhere.

## Run a real test after arrival

Turn on the travel line and wait several minutes for a local carrier or partner network to appear. Disable Wi-Fi, load an ordinary webpage and send a message. This confirms that traffic is passing through the cellular line rather than a remembered wireless network.

Signal without data points to the selected data SIM, roaming, allowance or APN. No carrier name at all points to registration. Cycle airplane mode for about thirty seconds before escalating; this restarts the search without erasing the profile.

## What successful activation looks like

The profile is listed, the line is enabled, the phone shows a network and a mobile-data test succeeds. A 4G or 5G icon is not conclusive while Wi-Fi remains connected.

The provider account may show a second status and remaining allowance. Check it after the first connection, especially for a plan counted in days. Save a screenshot if the displayed validity does not match the order.

## Avoid turning one problem into two

Do not scan the same QR code on several phones, erase a visible profile or copy an APN from an unrelated guide. Do not enable home-line roaming simply because the travel line has not connected yet.

Record the exact error and the steps already taken. If the code is reported as used, support needs to trace the existing download rather than watch another attempt. Related fault paths are collected under [Travel connectivity](https://yotti.net/en/blog/tag/Travel%20connectivity).
