An eSIM does not keep using the mobile network while Airplane Mode is active. The profile remains installed, but the phone’s cellular radio stops registering with a carrier. Approved onboard Wi-Fi may restore internet access, though that path does not use the eSIM plan.

## What the switch changes

Apple says Airplane Mode turns off mobile data and Wi-Fi, while Bluetooth may remain available. Wi-Fi can then be re-enabled separately if the airline permits it. SIM form factor is irrelevant here: both a removable card and an eSIM depend on the same cellular radio.

## Wi-Fi is a separate route

You may turn Wi-Fi back on without leaving Airplane Mode. Apps and messages can then travel through the onboard network. Calls and SMS depend on Wi-Fi Calling, carrier policy and plan support. Seeing the eSIM listed in settings does not mean it has a cellular connection.

## Restore service in a clean order

After landing, turn off Airplane Mode and allow time for carrier registration. Check the selected data line, then roaming only if the plan requires it. If 5G is absent, follow the [5G checklist](https://yotti.net/en/blog/why-your-esim-is-not-connecting-to-5g); for poor speed, use the [slow-data diagnosis](https://yotti.net/en/blog/travel-esim-running-slowly-how-to-find-the-cause); for bars without traffic, use the [no-internet sequence](https://yotti.net/en/blog/esim-has-signal-but-no-internet-what-to-check).

## A test that separates the two paths

With Airplane Mode on, switch Wi-Fi off: internet should disappear. Turn only Wi-Fi back on: access may return without cellular service. After landing, disable Airplane Mode and wait for the carrier name. The experiment distinguishes a stored profile from an active radio connection.
