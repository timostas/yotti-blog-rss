When SMS is not working on an eSIM, the first question is whether that plan has a phone number. A data-only travel eSIM cannot receive carrier text messages because there is no number for a sender to address. It can still run WhatsApp, iMessage, RCS and other internet services. Verification codes sent to your usual number remain attached to the home SIM, even when the travel eSIM supplies mobile data.

If the eSIM does include a number and the provider lists SMS service, check whether that line is switched on and registered with a network. A failure involving every sender points towards the line or carrier; one missing bank code is more likely to involve the sender, number format or a restriction on that type of message.

## Read the plan description before changing settings

Open the order confirmation and look for a telephone number, voice allowance or SMS details. A plan described as “data only” is doing its job when internet access works. The SIM menu may display it alongside a regular mobile subscription, but that screen does not add calling or texting to the product.

This distinction matters with travel plans. The current [Yotti](https://yotti.net/en/) order should say what the package includes. Where the order lists data and validity without assigning a number, account codes need to arrive on the home line or through an alternative offered by the service, such as email or an authenticated app.

Buying another data plan will not create an SMS number. The required product is a mobile line that explicitly includes a number and text messaging.

## Check where the sender delivered the message

A phone with two active lines has two separate addresses. Look at the masked number shown by the bank, airline or account page. The last digits often reveal that the code was sent to the familiar home number rather than to the new travel profile.

Changing the default data SIM does not move that number. The arrangement can be:

- home SIM on for calls and incoming codes;
- travel eSIM selected for mobile data;
- data roaming disabled on the home line;
- data roaming set on the travel line according to its instructions.

The home line still needs to register with a network abroad. Its carrier decides whether incoming SMS is available and what roaming charges apply. If the line shows no carrier or signal, restore its network connection before requesting another code.

## A numbered eSIM should appear as an active line

On iPhone, open Settings and Cellular or Mobile Data. Apple allows two numbered lines to send and receive iMessage, SMS and MMS when the carrier services support them. The default voice and messaging number is configured separately from the cellular-data line.

On Google Pixel, open Settings, Network & internet and SIMs. Google provides separate choices for calls, texts and mobile data. The text preference selects the line used for a new outgoing message; it does not reroute an incoming text that was addressed to the other number.

Confirm that the numbered eSIM is enabled and shows a carrier. If it has no network, toggling Airplane Mode or restarting the phone is a safer first step than deleting the profile. Once the line has service, ask someone to send a plain SMS directly to that number. A successful personal text shows that the basic SMS route works, even if a particular verification code still fails.

## Internet messages can hide the actual SMS result

Messages on the same phone can travel in different ways. iMessage uses an internet connection between Apple devices. RCS can provide an internet-based conversation where the phone and carrier support it. WhatsApp, Telegram and similar apps also rely on data. None of these tests proves that carrier SMS is available.

Use a short plain text from another mobile number for diagnosis. It should be addressed to the eSIM’s own number, with the international country code where appropriate. If that arrives while an app message does not, investigate the app registration or internet connection. If app messages work and the plain SMS does not, the numbered mobile line needs attention.

The reverse is common with account codes: personal texts arrive, but one automated sender remains silent. Check the saved number and country code, then wait before requesting another code. Repeated requests can trigger a temporary sender limit. Short-code delivery, fraud controls and roaming routes are controlled by the bank or carrier, so an alternative sign-in method may be quicker than changing the phone.

## Keep the test narrow

APN settings affect mobile data, not the ability of a numbered line to receive an ordinary SMS. Switching the data line, resetting all network settings or reinstalling the profile adds new variables without answering the original question.

A useful sequence is short:

1. Confirm that the plan includes a number and SMS.
2. Verify the number the sender used.
3. Check that the corresponding line is on and has network service.
4. Send one ordinary test SMS from another phone.
5. If only one service fails, use its recovery option or contact that sender.

This sequence also protects the home SIM. It can remain available for codes while the travel eSIM carries data, without enabling home-line data roaming.

## What support needs to investigate

If a numbered eSIM has network service but receives no ordinary test message, give the provider the order number, exact phone model, current country, visible carrier and approximate test time. State separately whether calls, outgoing SMS and mobile data work. That pattern is more useful than a screenshot of the Messages inbox.

Do not erase the eSIM while the provider checks it. Crop QR codes, one-time passwords and complete device identifiers from screenshots. Keep the profile installed until support has finished examining the line.
