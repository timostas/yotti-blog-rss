Turn off the travel line in the phone's SIM settings when you want to pause an eSIM. The installed profile stays on the device and can be enabled again later. Deleting the eSIM is a separate action that may require the provider to issue or approve another activation.

Take a screenshot of the current line names and data assignment first. The important change is not only the on-off switch: the phone also needs an explicit instruction about which remaining line may carry cellular data.

## Choose the replacement data state first

Decide what should happen during the pause. There are three sensible states:

- the home SIM supplies data under known terms;
- another travel profile supplies data for the next country;
- cellular data stays completely off.

Set that state, then disable the old travel line. If automatic data switching is enabled, review it at the same time. Otherwise a phone can preserve connectivity by using a line whose roaming cost you have not checked.

Disabling a profile does not freeze the package. A validity period may continue according to the order terms while the line is off. Treat the account clock and the handset switch as separate controls.

## The iPhone control belongs to each plan

Open Settings, choose Cellular or Mobile Data, and select the labeled travel plan. Turn off the line control shown for that plan. Return to Cellular Data and confirm the intended data line.

Apple's international travel guidance tells returning users to make sure the primary line is on and to turn off travel eSIM lines that are no longer in use. It also distinguishes this from erasing an eSIM. The wording of the switch can vary by iOS release and locale, so identify the plan by its label and order.

Leave the erase command alone. A temporary pause should still leave the profile visible in the cellular-plan list.

## Android menus are model-specific

On a compatible Pixel, SIM controls sit under network settings and allow a SIM to be enabled, disabled or assigned for data. Samsung and other Android manufacturers use their own labels and menu paths. Follow the manual for the exact model if the SIM list is unclear.

Confirm the profile before touching its switch. Match the label, provider and any identifier available in the order. A network reset is unnecessary for a planned pause and can remove useful diagnostic information. If the only visible action says Delete or Erase, stop and consult the manufacturer or provider rather than treating it as an off switch.

## Four reasons to pause a line

### The trip has ended

Restore the home data setting, disable the travel profile and retain the order. Whether the same profile can accept another package is a provider rule. Its presence on the phone is useful evidence, not a promise of reuse.

### A different country plan takes over

Label profiles by route segment and switch the data assignment at the border. Check the country list and balance for the newly active order before using it.

### You are isolating a network or battery issue

Run a bounded comparison with the second line off and otherwise similar use. If the symptom disappears, repeat the observation before drawing a conclusion. The test identifies a condition worth investigating; it does not prove the eSIM file is defective.

### The line must remain unavailable for a while

Disabling it prevents ordinary service on that profile. It does not replace a screen lock, account security or safe storage of the activation details.

## Bring the line back with a controlled test

Check the order's validity and country coverage while connected to trusted Wi‑Fi. Enable the stored profile, select it for data and keep automatic switching off during the first test. Disable Wi‑Fi and load a lightweight page.

If data works, confirm the provider balance. If the line is present but offline, verify roaming instructions, coverage and package state, then toggle Airplane Mode once. If the profile is missing altogether, do not repeatedly scan an old code; contact the provider with the order and exact device model.

Unexpected home-line data is the priority failure. Turn cellular data off until the assignment and roaming terms are understood. Do not erase neighboring profiles to simplify the screen.
