If an eSIM will not install, resist the urge to scan the QR code repeatedly or erase whatever has appeared in Settings. First look at the phone’s SIM list. The download may already be complete, with the problem occurring later when the line is switched on or tries to join a network. If no new profile exists, the failure is usually easier to place: the phone offers no eSIM option, the QR code is not recognised, or the download starts and then stalls.

Keep the order email open, connect to dependable Wi-Fi and write down the exact error. There is no need to disturb the main SIM while diagnosing an eSIM download. Treat the QR code as private activation data rather than something to include in a public screenshot or support chat.

## Check whether setup has already finished

On an iPhone, open Settings and Cellular or Mobile Service. On a Google Pixel, look under Settings, Network & internet and SIMs. Other Android brands arrange the same controls differently.

If the travel line is listed, installation has finished. Give it a clear label and stop using the QR code. A line that is off, has no carrier name or cannot load a webpage needs post-installation troubleshooting. Those subjects are kept separate in Yotti’s [Travel connectivity](https://yotti.net/en/blog/tag/Travel%20connectivity) section so that a setup problem is not confused with registration or mobile-data settings.

If the profile is absent, identify the last screen that worked. Did the phone lack an Add eSIM command? Did the scanner ignore the code? Was the code accepted before an error appeared? That detail gives support far more to work with than “the eSIM does nothing”.

## No eSIM control appears

An absent menu is a device question before it is a QR-code question. eSIM support can vary by model, market and carrier version, even where two phones have nearly identical retail names. This article does not attempt to turn the compatibility check into part of every installation fix; it is a separate decision that should be settled before consuming an activation code.

Install the latest operating-system release available to that device, restart it and return to the SIM settings. Google’s current Pixel route is Settings, Network & internet, SIMs, Add SIM and Set up an eSIM. On an iPhone, Add eSIM sits inside the cellular settings.

If the command remains missing, collect the full model name and regional model number. Avoid unofficial “hidden menu” instructions. They cannot add hardware or carrier support and may change unrelated network settings. Leave the QR code unused until the phone’s compatibility is confirmed.

## The scanner ignores the QR code

Launch the scanner from Add eSIM rather than the ordinary camera app. Display the whole code on a laptop, tablet or another phone, with enough brightness to remove shadows but no strong glare. A printed copy should be flat and sharply visible.

When the order is open on the same device, check whether the provider supplies an installation link or manual activation details. Use only the method attached to that order. An SM-DP+ address copied from a forum cannot lead the phone to your purchased profile.

Families and groups should also confirm who owns each code before scanning. Several confirmation emails can look alike. Open the relevant [Yotti](https://yotti.net/en/) order and match the destination, traveler and device without exposing the activation image itself.

## A recognised code is rejected

Preserve the wording on screen. “Invalid”, “already used” and “not supported” are different reports, even when each prevents the same installation. Before another attempt, return to the SIM list in case the profile downloaded in the background. Also check whether that order was previously used on another phone.

Some setup flows depend on the provider having activated the order on its side. Google directs Pixel owners with persistent setup trouble to their carrier, which may ask for an IMEI or device identifier. Apple similarly recommends recording the error and having the iPhone’s IMEI or EID ready when contacting the network provider.

Share identifiers only through an official support channel. For the first investigation, support should have the order number, phone model, country or market where the phone was sold, and a screenshot with the QR code and other secrets cropped out. A one-time password or account password should not be pasted into a troubleshooting message.

## Downloading hangs after confirmation

Profile downloading needs a working internet connection. Confirm that an ordinary webpage opens over the current Wi-Fi. If the connection is unreliable, move to another trusted network or use a personal hotspot. The regular SIM can stay in place throughout this check.

After a clear failure, restart the phone and inspect the SIM list before scanning again. Apple’s troubleshooting sequence includes toggling Airplane Mode, checking whether the line is shown and restarting the iPhone. These steps refresh the connection without erasing the downloaded profile. When the line appears, installation is over; any remaining fault belongs to activation or network registration.

APN changes and data roaming do not repair an unfinished profile download. Leave them alone at this stage, particularly on the home SIM. Changing several network controls together makes it harder to identify what actually failed.

## Give support the details that separate the causes

A short, precise report is usually more useful than a long account of every tap. Include:

- the order number, without attaching the QR code;
- the exact phone model and software version;
- the country and retailer from which the phone came;
- the point where setup stopped;
- the full error wording and approximate time;
- the IMEI or EID only when official support requests it;
- checks already completed, such as another Wi-Fi network, a restart and a second look at the SIM list.

Keep the main SIM and the original order email while the case is reviewed. Do not erase a line that has appeared, and do not buy a replacement plan after a single failed screen. Ask the provider to confirm whether the profile is still available for download. That answer determines whether to retry on the same phone, use another installation method or request a replacement code. If the Add eSIM command never appeared, return to the [phone compatibility check](https://yotti.net/en/blog/which-phones-support-esim-how-to-check-before-you-buy). If the profile is already visible, continue with the separate [activation and connection test](https://yotti.net/en/blog/how-to-activate-an-esim-and-confirm-it-is-working).
