Installing a travel eSIM at home is usually easier than doing it after landing. Reliable Wi-Fi, access to the order email and time to read each prompt reduce avoidable errors. Installation and plan activation are not always the same event, however. A plan may begin when the profile is installed, when it first joins a supported network, or according to another provider rule.

Check that condition before scanning anything. Do not assume every travel plan waits for arrival. The current instructions attached to the selected [Yotti eSIM](https://yotti.net/en/) should decide when you install and turn on the line.

## Prepare the phone and activation details

Confirm support for the exact phone model and make sure it is not locked to another carrier. Update the operating system within the version supported by the device, restart it and connect to dependable Wi-Fi.

Open the QR code on another screen or print it. If it is displayed on the same phone, some recent iPhones can recognise a code from Mail or the default browser, although the option depends on the software version. Keep the order number and support contact separately.

Treat the QR code and any confirmation code as private activation data. Many are intended for one download. A screenshot shared in a public chat can allow someone else to consume the profile before you do.

## Add the plan on an iPhone

Open Settings, Cellular or Mobile Data, and Add eSIM. Use the method supplied with the order: QR code, carrier link, provider app or manual details. Apple also supports direct carrier activation where the network offers it.

Once the profile appears, label it with a plain name such as “Travel”. Rename the regular line “Home”. These labels make the data choice much clearer after a long journey.

Leave the travel line off until arrival if the plan instructions permit this. Keep the home SIM or Wi-Fi as the current data source. Review Allow Cellular Data Switching as well: leaving it on can let the phone fall back to the home line abroad and create roaming charges.

## Add the plan on Android

On a current Google Pixel, the path normally runs through Settings, Network & internet, SIMs, Add SIM and Set up an eSIM. Samsung Galaxy phones generally place Add eSIM inside Settings, Connections and SIM manager. Other Android interfaces use similar terms in different locations.

Scan the code, approve the download and wait for the new line to appear. Give it a destination-based label. Do not make it the data line at home until you know what triggers validity and whether the plan can join a partner network where you are.

## What can be checked before departure

The profile appearing in the SIM list confirms that the download completed. You can verify its label and available controls without sending data through it. A provider app may also show whether the profile is installed and whether validity has started.

Do not treat a lack of signal at home as proof of failure. A destination plan may have no partner network in your current country. The meaningful test happens after arrival, unless the provider explicitly offers a test network.

## Turn it on after landing

Enable the travel line, select it for mobile data and set data roaming exactly as the plan requires. If the home line remains active for calls or verification messages, prevent it from carrying mobile data abroad.

Give the phone a few minutes to register. Load an ordinary webpage and send a message. If there is still no connection, check the selected data line, roaming and airplane mode one at a time. Do not erase the profile during first-line troubleshooting; the original code may not support another download.

A profile that is present but cannot find a network is a different problem from installation. The related troubleshooting material sits under [Travel connectivity](https://yotti.net/en/blog/tag/Travel%20connectivity), where network registration can be diagnosed without repeating the setup guide.
