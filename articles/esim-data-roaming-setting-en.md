Turn Data Roaming on for a travel eSIM when the plan instructions require it or when the line has signal but cannot pass data with the setting off. Many travel profiles use a partner network. The roaming label describes how that line reaches another network; it does not by itself mean that your home carrier is carrying the session.

The safe arrangement is line-specific: select the travel eSIM for cellular data, enable roaming on that line if needed, and leave roaming off on the home SIM. A tariff, not the switch label, determines whether a line can incur a charge.

## Give each SIM one clear job

Open the SIM or Cellular settings before changing roaming. Confirm that the travel profile is enabled and selected for mobile data. Temporarily disable automatic cellular-data switching so the phone cannot move to the home line during a weak-signal test.

Rename the profiles if they still have generic labels. “Home” and “Travel” make the next screen much less ambiguous than “Primary” and “Secondary”. If ordinary webpages already load through the travel eSIM, there is no benefit in changing a working setting merely because another guide shows a different toggle position.

Apple places cellular options, including Data Roaming, under each selected line on a Dual SIM iPhone. Google defines roaming as allowing a phone to send data over other carriers’ networks outside the SIM’s own coverage. Both direct users back to the carrier for the commercial policy, because the handset cannot display the full tariff agreement.

## The iPhone route

Open Settings, then Cellular or Mobile Data. In Cellular Data, select the travel eSIM. Return to the list of SIMs, open that travel line, choose Cellular Data Options and turn Data Roaming on when the provider tells you to use it.

Open the home line separately and keep its Data Roaming control off. If Allow Cellular Data Switching is available, switch it off for the first test. That prevents an apparently successful page load from being supplied by the home plan.

Disable Wi‑Fi and load a plain website. A bank, streaming service or work login is a poor first test because it can reject an IP address even while mobile data is healthy.

## The Android route

On a Pixel, open Settings, Network & internet and SIMs. Select the travel eSIM, enable it, assign mobile data to it and then change Roaming. Google notes that the exact controls can vary by model, Android version and carrier.

Samsung and other manufacturers may place the same choices under SIM manager or Mobile networks. Follow the roles rather than memorising a label: identify the data SIM first, then adjust roaming for that SIM. On a device with one global roaming control, temporarily disabling the home SIM reduces the chance of testing the wrong line.

## Read the result, not just the icon

### Data starts only when roaming is on

Keep the control on for the travel profile and check the order details. This is a valid configuration when the plan relies on a partner network. The home SIM does not need the same permission.

### Data works in either position

Retain the working setup. Network arrangements differ between plans and places; an unnecessary settings change adds no reliability.

### The line has bars but no data in either position

Check the package balance and expiry, the selected data SIM and the provider’s setup notes. Toggle Airplane Mode briefly or restart once. If the fault remains, collect the country, phone model, local network name and the results with roaming on and off.

### The home line records unexpected usage

Turn mobile data off on that line immediately and disable automatic switching. Per-line device statistics can show which SIM carried data, while the home carrier must confirm any charge and its billing rules.

## Keep the fallback intact

Do not erase the eSIM or rescan its QR code. Roaming is a permission for an installed line; reinstalling cannot improve the tariff and may require replacement activation details.

Do not enter an APN from a generic forum unless the provider supplied it for this order. A full network-settings reset is also disproportionate before a controlled test because it removes saved Wi‑Fi and changes other connections.

Save the order number and review [how a Yotti eSIM works](https://yotti.net/en/how-it-works) before departure. Plans for the trip are listed in the [Yotti catalogue](https://yotti.net/en/catalog). If the line still cannot pass data, use trusted Wi‑Fi to send support the two roaming-test results. Keep the activation QR code out of screenshots.
