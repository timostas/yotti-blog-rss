Signal bars and a local carrier name mean the eSIM has registered on a network. If webpages still do not load, the likely causes are now narrower: another line is selected for data, the travel line needs data roaming, the allowance has ended, or the plan requires a specific APN. Test one change at a time.

Do not erase the profile or reset every network setting first. Those actions can remove useful evidence and may create another installation problem. Check the package status in the order or your [Yotti account](https://yotti.net/en/) before changing the phone.

## Select the travel line for data

On iPhone, open Settings, Cellular and Cellular Data, then select the travel line. On Pixel, choose the data SIM under Network & internet and SIMs. Samsung uses Primary SIM or Mobile data inside SIM manager.

Turn off automatic cellular data switching during the test. Otherwise the phone may fall back to the home line, particularly when its signal is stronger. Abroad, that behaviour can also create roaming charges.

## Apply roaming to the correct SIM

Many travel eSIMs reach a destination through a partner network and therefore need data roaming enabled. That does not mean enabling roaming on the home SIM. Open the travel line itself and follow the plan instructions.

After changing the setting, wait a minute and turn off Wi-Fi so the test genuinely uses mobile data. Load a simple webpage. An app with cached content, an expired login or its own outage is a poor first test.

## Check allowance and validity

The network indicator can remain after a package runs out. Confirm the remaining data, expiry and any speed policy. A daily allowance may reset according to the provider's time zone rather than local midnight; the order terms are the reliable reference.

Disable a VPN and data-saving mode briefly. Neither always breaks connectivity, but each can affect selected apps and make a partial problem look like a total data failure.

## Change APN only from the plan instructions

The access point name tells the phone how to route mobile data. Some eSIM profiles install it automatically; others need a manual value. An APN copied from a forum or another country's guide can leave the line registered but unusable.

Compare the field character by character with the provider instructions, including spaces. iPhone does not expose manual APN controls for every carrier. On Android, the menu is normally inside the selected SIM's mobile-network settings. Save the entry and make sure it is selected.

## Test the network rather than one app

Open two unrelated websites and send a message. If the browser works while one app fails, the mobile connection is functioning. Look instead at that app's cellular permission, VPN behaviour, regional availability or service status.

If nothing works, cycle airplane mode for about thirty seconds and restart the phone. Re-select the travel SIM for data after boot. Leave Reset Network Settings for a support-led final step because it removes saved Wi-Fi networks and other configuration.

## Send support a concise diagnosis

Include the order number, country, phone model, registered carrier and the result of each test. Screenshots of the selected data line, roaming control and APN are useful as long as they exclude the QR code and private identifiers.

If the carrier name disappears, return to network-registration troubleshooting. If data works on the phone but not through a laptop, examine hotspot support and plan restrictions instead.
