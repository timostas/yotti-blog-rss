An eSIM showing LTE or 4G instead of 5G is not necessarily faulty. Four conditions need to line up: the exact phone must support the local 5G bands, the plan must include 5G access, the travel provider’s partner network must allow it, and coverage must reach the place where you are standing. If one is missing, falling back to LTE is normal.

Do not reinstall the profile or edit the APN to chase a status-bar icon. Establish what the plan promises first.

## 5G belongs to the whole connection, not the SIM format

An eSIM is a way of storing carrier credentials. It does not upgrade the radio hardware or add 5G to a data package. A compatible handset can still remain on LTE when its current carrier arrangement does not include 5G roaming.

On iPhone, Apple lists iPhone 12 and later as the starting point for 5G. Android support depends on the exact model, sales region and network. Google notes that not every Pixel 4a (5G) or later works with every kind of 5G network.

The plan is the next boundary. Check the current order rather than assuming that every package sold for a 5G phone includes 5G. Then look at the named partner and destination coverage. Local customers and roaming profiles do not always receive identical network access.

## Read the icon carefully

Apple’s default 5G Auto setting uses Smart Data mode. The iPhone can switch to LTE when 5G would not deliver a noticeably better experience, conserving battery. This is expected behaviour rather than a failed eSIM.

Google makes a related distinction: the 5G icon can appear when a phone is in an area where 5G is available, without proving that the current session is using 5G at that moment. A network label is not a speed measurement.

Judge the connection by the task. If navigation, browsing and calls are stable, LTE may be more useful than a weak 5G signal. A connection that remains slow on both networks belongs to speed troubleshooting rather than 5G eligibility.

## Check the travel line on iPhone

Open Settings, Cellular or Mobile Data, select the travel eSIM, then choose Voice & Data. Depending on the device and carrier, the choices can include:

- **5G Auto**, which moves between 5G and LTE as conditions change;
- **5G On**, which uses 5G whenever available and may use more battery;
- **LTE**, which prevents a 5G connection.

Use 5G Auto as a clean baseline. If no 5G option appears, Apple advises confirming that the carrier and plan support it, checking coverage and toggling Airplane Mode. With Dual SIM, make sure the settings belong to the travel line rather than the home number.

Low Power Mode restricts 5G in some circumstances on certain iPhones. A change that follows battery saving may therefore be intentional.

## Check the network preference on Android

On Pixel, open Settings, Network & internet, SIMs, select the operator and review Preferred network type. The choices vary by country and carrier. Select the recommended 5G-capable mode if it is offered, then allow the handset to register again.

Pixel Battery Saver turns 5G off. Other Android manufacturers apply their own adaptive-network and power-saving behaviour, so use the official instructions for the exact model.

Hidden engineering menus are a poor shortcut. Forcing an unsupported band can remove a stable connection and leave support with a modified configuration to untangle.

## Why a travel plan can receive LTE only

International plans use partner networks. Apple notes that when a carrier does not support 5G roaming, cellular data can continue through 4G or LTE. The local operator may advertise broad 5G coverage to its own customers while a particular partner profile remains on LTE.

Check whether 5G is explicitly listed in the [Yotti](https://yotti.net/en/) order for that destination. A 5G On switch cannot create a benefit that the plan does not provide. Coverage maps are useful for the wider area but cannot guarantee service inside a hotel, train or historic building.

## Decide whether 5G improves the actual task

Stable LTE is sufficient for maps, tickets, messaging and ordinary browsing. The difference becomes more visible during a large download, video call or hotspot session, which also consumes a limited allowance more quickly. A status icon is therefore a poor goal on its own.

At the edge of coverage, a handset can alternate between 5G and LTE. Those transitions may feel less consistent than a fixed LTE connection. If a call or download fails whenever the icon changes, selecting LTE briefly is a useful diagnostic comparison. Return to the automatic mode afterwards; a fixed choice is less suitable for a journey through several cities and partner networks.

Two nearby 5G phones can still record different results because their plans, supported bands and background use differ. That comparison does not establish that either eSIM profile is defective.

## A useful support report

Turn Wi-Fi off, move outdoors, select the recommended network mode and toggle Airplane Mode once. Record the phone model, software version, country, visible partner network and whether LTE data works. State whether the order advertises 5G.

Working LTE with no 5G promise is a normal result. Where 5G is included, the device is compatible and nearby customers on the same network receive it, the provider can check the profile’s network access.
