A travel eSIM may start its validity when the profile is installed, when it first connects to an eligible network or at another event specified by the provider. There is no universal trigger. Treat purchase, profile download, turning on the line and the start of package validity as four separate moments.

The decisive wording belongs to the particular [Yotti order](https://yotti.net/en/), not to a general iPhone or Android instruction. The phone controls a line; it does not define the plan's commercial clock.

## Purchase can have its own deadline

After payment, the provider supplies a QR code, link or in-app installation. The order may set a deadline for downloading the profile. That installation window is different from the number of days of mobile data.

If the trip moves, check both dates: the last date on which the profile can be added and the validity after activation. Keep the original order because a public plan page can change later.

## Installation places the profile on the phone

Scanning the code downloads a digital profile and adds a new line to the SIM list. Some plans begin at this point. For others, installation is preparation only.

Where installation starts the clock, adding the profile weeks early wastes validity. Where first connection in the destination is the trigger, advance installation is often sensible, provided it happens within the permitted download window.

## Turning the line on is another event

An enabled eSIM searches for an available network. A destination-only profile may show no signal at home, but a regional plan can sometimes find a partner there. Geography alone is therefore not a reliable safeguard.

Keep the travel line away from the data role until needed, and review automatic data switching. This prevents the phone from sending traffic through it unexpectedly.

## First network use is common, not guaranteed

Providers may start validity at the first registration on a supported network or first data session. After landing, enable the line, apply the stated roaming setting and wait for a carrier. Then check the provider app or account.

Record the local time of first connection and take a screenshot of the displayed expiry. This helps if a package counts days in another time zone or the account shows an unexpected end date.

## Three questions settle the timing

Before departure, find exact answers to:

1. Which event is named as activation?
2. By what date must the profile be installed?
3. How many hours or calendar days follow the trigger?

If the terms are unclear, ask support before scanning. “Can I install early?” is ambiguous; ask whether downloading the profile starts validity for that specific order.

Deleting the profile does not normally pause an active package and can prevent another installation. Setup and first-connection guidance is available under [Travel connectivity](https://yotti.net/en/blog/tag/Travel%20connectivity).
