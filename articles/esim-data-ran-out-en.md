An exhausted travel eSIM plan does not require a fresh installation. Connect to trusted Wi-Fi, check the provider's balance and expiry, and renew the existing plan or purchase the appropriate replacement. Once the account confirms service, toggle mobile data and test a small web page.

Three different events can look like “the data ran out”: the provider allowance reached zero, Android enforced a device limit, or the phone selected another SIM for data. Identify the branch before paying or changing network settings.

## The account shows zero data or an expired plan

The provider's record is the authority for the commercial allowance. Yotti says an eSIM profile remains installed after its data or validity ends and can be topped up through the account without another installation. A daily unlimited plan may slow after its high-speed threshold rather than stop, so read the exact product status.

Check both quantity and time. A zero balance points to renewal or a new bundle. An expired validity period will not be repaired by closing apps. If the provider shows usable data and a current end date, inspect the phone's local controls next.

## Android reached a limit set on the handset

Pixel phones can switch mobile data off automatically at a user-defined threshold. Open Settings → Network & internet → SIMs → Data warning & limit. Check the selected eSIM and the measurement period before raising the number.

Google cautions that the handset and carrier can measure usage differently. A device counter is useful for warnings and app-level investigation; it should not override the balance shown for the purchased plan.

When the local limit caused the stop, increase or disable it only after confirming that the provider allowance remains. Otherwise the phone may resume spending data that you intended to preserve.

## iPhone statistics show use but do not define the balance

On iPhone, Settings → Cellular lists usage by app for the current period. Apple lets the user reset that period manually, so its starting point may have no relationship to the travel plan's activation date. Use the list to spot streaming, cloud backups or Wi-Fi Assist, then return to the provider account for the actual remaining allowance.

An iPhone data total larger than the plan does not prove that the current eSIM is empty. With Dual SIM, confirm that the statistic belongs to the selected data line and that the counter was reset when expected.

## The wrong SIM is carrying—or blocking—data

Open the SIM settings and confirm that the travel profile is enabled and selected for mobile data. Apply data roaming only to the line whose instructions require it. Keep home-line data roaming off while investigating so a failed travel plan cannot produce an unintended roaming session.

If the eSIM has network service and the account shows an active balance, select it again as the data line and wait a few minutes. Avoid changing APN or forcing a network at this stage. Running out of an allowance does not corrupt either setting.

## Renew without erasing the eSIM

Use Wi-Fi to open the account and choose a top-up for the existing eSIM when the order offers one. Verify destination, amount and validity before payment. If only a new plan is available, find out whether it attaches to the installed profile or comes with new activation credentials.

Wait for a clear active status. Re-scanning the old QR code is unsafe because activation codes may be single-use. Deleting the profile also removes useful diagnostic state and may make reconnection harder.

Current options are available in the [Yotti catalogue](https://yotti.net/en/catalog), while the [setup page](https://yotti.net/en/how-it-works) shows how to select the travel line. Save the order number and a screenshot of the balance until service is back.

## Use one page to confirm the renewed plan

Turn Wi-Fi off, toggle mobile data for the travel eSIM and load one lightweight page. Refresh the account and look for a small change on the correct plan. That pair of checks confirms both routing and allowance use.

If the account still shows active data and the page fails, stop making broad changes. Give support the order number, country, phone model, last successful connection time and a screenshot of the selected line with the QR code hidden. That evidence is more useful than a network reset and preserves a safe return path if the provider needs to change the plan remotely.
