# Подготовка технического выпуска — 22 августа 2026

## Объём

Сегодня готовится пакет из десяти первых технических тем очереди. Каждая тема
создаётся как самостоятельная RU/EN-единица; это двадцать локализованных
текстов, а не один текст с автоматическим переводом. Остальные десять тем
остаются в очереди и не используются для заполнения объёма при провале
качества.

## Ворота уникальности

Перед каждым черновиком фиксируются главный вопрос, соседние темы из очереди,
уникальный результат для читателя и две внутренние ссылки. Статья не проходит,
если её можно превратить в соседнюю заменой нескольких слов. Внутри пакета
запрещены одинаковые лиды, FAQ, выводы, списки «проверьте сначала» и
универсальные рекламные абзацы.

Для диагностических материалов обязательны минимум три разные развилки
решения: например, устройство, настройки линии и регистрация в сети. Если
различие iPhone/Android действительно меняет шаг, оно описывается отдельно;
если нет — искусственная ветка не добавляется.

## Редакционный маршрут

1. Sol/high готовит исследовательское резюме и RU-версию.
2. Sol/high самостоятельно локализует EN-версию с сохранением фактов, но не
   синтаксиса и не русского поискового шаблона.
3. Sol/high выполняет отдельный человеческий редакторский проход каждой
   локали: заголовок читается вслух, машинные связки и повторные выводы
   удаляются.
4. Luna/low используется только для метаданных, проверки полей, XML и
   детерминированных отчётов; Luna не пишет и не редактирует основной текст.
5. После десяти пар выполняются общие style-check, queue-report, тесты, сборка
   и визуальная проверка RSS. Любая ошибка останавливает пакет.

## Автономность

Работает один активный контур `yotti-blog`. Он использует worktree проекта,
запускается ежедневно утром и готовит четыре пары по четырём слотам. Для
сегодняшнего расширенного выпуска используются те же правила и модель Sol/high,
но ручной выпуск дополнительных проверенных пар разрешён политикой владельца.
Новые параллельные cron-контуры не создаются.

## Критерий готовности

Пакет готов только после прохождения всех десяти пар по scorecard, отсутствия
дублей интентов и успешной сборки. Владелец получает только сообщение о
готовности RSS к ручной синхронизации; незавершённые или сомнительные темы не
публикуются ради выполнения числа десять.
